# ДРУГИНЯ — v3

Итерация сайта с переработанными первым и вторым экранами и системой переходов между секциями.

Изменения v3:
- первый экран больше не использует текст, зашитый в изображение;
- логотип «ДРУГИНЯ» вынесен в отдельный HTML-слой и набран отдельной editorial-гарнитурой;
- дата, Telegram и «бесплатно» — отдельный HTML-текст;
- второй экран пересобран из фото + HTML-типографики и 2×2 композиции ценностей;
- между секциями добавлены органические визуальные «мосты» через формы и перекрытия;
- сохранены реальные HTML-тексты, кнопки, форма и анимации.

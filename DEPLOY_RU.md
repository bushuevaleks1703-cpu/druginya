# Публикация сайта «Другини» через GitHub и Vercel

## 1. Подготовить файлы

В корне проекта должны находиться:

- `index.html` — сам сайт (все изображения уже встроены в него);
- `README.md` — краткая информация о проекте;
- `DEPLOY_RU.md` — эта инструкция;
- `vercel.json` — минимальная конфигурация статического сайта;
- `.gitignore` — исключения для временных файлов.

Не переименовывайте `index.html` и не переносите его в подпапку: Vercel должен видеть его в корне репозитория.

## 2. Создать репозиторий на GitHub

1. Войдите в GitHub и нажмите **New repository**.
2. Назовите репозиторий, например `drugini-landing`.
3. Выберите **Private**, если пока не хотите открывать исходник публично. Сам опубликованный сайт при этом может быть доступен посетителям по ссылке Vercel.
4. Создайте репозиторий. Если загружаете готовые файлы через веб-интерфейс GitHub, используйте **Add file → Upload files**.
5. Загрузите файлы из этой папки, обязательно вместе с `index.html` в корень, и нажмите **Commit changes**.

### Вариант через Git в терминале

Изнутри распакованной папки проекта выполните:

```bash
git init
git add index.html README.md DEPLOY_RU.md vercel.json .gitignore
git commit -m "Deploy Drugini landing page"
git branch -M main
git remote add origin https://github.com/ВАШ-АККАУНТ/drugini-landing.git
git push -u origin main
```

Замените `ВАШ-АККАУНТ` на свой GitHub username и при необходимости поменяйте URL репозитория.

## 3. Подключить GitHub к Vercel

1. Войдите в Vercel.
2. Выберите **Add New → Project** (название пункта может немного отличаться).
3. Импортируйте репозиторий `drugini-landing` из GitHub. Если Vercel ещё не имеет доступа к репозиторию, разрешите доступ к нему.
4. В настройках проекта укажите:
   - **Framework Preset:** `Other`;
   - **Root Directory:** `./` (корень проекта);
   - **Build Command:** пусто / без команды сборки;
   - **Output Directory:** `.` если поле обязательно, иначе оставьте значение по умолчанию;
   - **Install Command:** не требуется.
5. Нажмите **Deploy**.
6. После завершения откройте выданный домен `*.vercel.app` и проверьте сайт на телефоне.

## 4. Проверка после публикации

Проверьте:

- изображения присутствуют на всех пяти экранах;
- бургер открывает и закрывает меню;
- логотип возвращает на первый экран;
- «ПРОГРАММА» ведёт к программе;
- «ПРИНЯТЬ УЧАСТИЕ» ведёт к форме;
- форма отмечает незаполненные обязательные поля;
- при заполнении формы показывается честное сообщение, что отправка пока не подключена;
- сайт не создаёт горизонтальную прокрутку при ширине 390 px.

## 5. Как обновлять сайт позже

Замените `index.html` в GitHub новой версией и выполните commit. Vercel автоматически запустит новое развёртывание.

## Важно про форму

Сейчас форма не передаёт имя и Telegram никуда. Чтобы собирать заявки, нужно отдельно подключить серверный endpoint или проверенный сервис форм, а также определить, куда должны поступать данные. Не добавляйте секретные API-ключи в `index.html`: всё, что находится в клиентском HTML/JavaScript, доступно посетителям сайта.

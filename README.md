# ДРУГИНЯ — v8

Мобильная версия hero переработана по последним правкам: логотип только в шапке, название мероприятия в две строки над головой девушки, мета-информация отдельным HTML-текстом, CTA внизу, без полукруга между секциями. Hero ориентирован на 390×844 и собран как единая композиция с плавным продолжением в следующий экран.


Hero v8 uses the approved full-bleed mobile hero artwork as the visual source, with transparent HTML hit areas for logo/program/CTA navigation.

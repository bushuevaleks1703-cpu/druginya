# ДРУГИНЯ — v5

Мобильная версия лендинга, ориентированная на ширину 390 px.

## Последние изменения
- чистая структура репозитория без вложенной `images/images`;
- первый экран: живой HTML-текст отдельно от фотографии;
- логотип «ДРУГИНЯ» отдельной editorial-гарнитурой;
- дата / Telegram / бесплатно вынесены в отдельный HTML-элемент;
- второй экран переработан как самостоятельная композиция с фотографией и четырьмя направлениями;
- между секциями добавлены визуальные переходы;
- изображения не растягиваются: сохраняют исходные пропорции, для кадров используются контролируемые `object-fit` только там, где нужен аккуратный кроп;
- программа и остальные секции остаются редактируемыми HTML/CSS.

## Структура
- `index.html`
- `style.css`
- `script.js`
- `images/`

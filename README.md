# «Другини» — сайт для GitHub + Vercel

Это статический сайт без сборщика и без внешних файлов изображений. Все пять экранов и изображения встроены непосредственно в `index.html`.

## Быстрый запуск локально

Откройте `index.html` в браузере. Для публикации используйте GitHub и Vercel по инструкции в `DEPLOY_RU.md`.

## Что важно знать

- Главный файл сайта — `index.html` в корне репозитория.
- Сайт не требует `npm install`, `npm run build` или отдельной папки `assets`.
- В настройках Vercel оставьте Framework Preset = **Other**; Build Command и Output Directory можно оставить пустыми/по умолчанию. Если интерфейс просит Output Directory, укажите `.`.
- Форма проверяет обязательные поля, но пока **не отправляет данные**: получатель/CRM/бот не подключён. Не используйте её для сбора заявок в продакшене, пока не подключите безопасный обработчик отправки.
- Визуальная версия предназначена прежде всего для мобильной ширины около 390 px.

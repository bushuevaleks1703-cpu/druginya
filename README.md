# ДРУГИНЯ — web prototype v2

Mobile-first landing, рассчитанный на ширину 390px.

Структура:
01 Hero
02 Кто такие Другини?
03 Жить на свой лад / программа
04 Как всё проходит
05 И кое-что можно забрать с собой
06 Регистрация

В v2 ключевой контент экранов 1–3 вынесен из картинок в HTML там, где это возможно:
- реальный заголовок;
- реальные CTA;
- реальное расписание;
- реальные тексты;
- реальная форма регистрации.

Анимации:
- reveal при появлении секций;
- очень мягкий scroll-параллакс hero;
- дыхание света на hero;
- scroll hint;
- reduced-motion режим.

Изображения лежат отдельно в images/.
